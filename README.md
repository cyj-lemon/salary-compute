# 2026 个人税前税后收入计算器

面向北京、上海、广州、深圳上班族的纯前端收入计算器。支持按月生效的五险一金政策、上海补充公积金、累计预扣法、专项附加扣除、现金房补、签字费发放计划、年终奖两种计税方案、上市公司股权激励单独计税、城市对比与月度明细。

当前开发状态、政策复核进度、已知问题和后续任务统一记录在 [PROGRESS.md](./PROGRESS.md)。继续开发前请先阅读该文档。

## 口径

- 计算年度固定为 2026 年，政策数据核验日期为 2026-09-25。
- 居民个人工资薪金按累计预扣法计算，基本减除费用为 5,000 元/月。
- 全年一次性奖金同时计算单独计税和并入综合所得，汇总结果采用税额较低的方案。
- 月度现金房补进入工资薪金；签字费总额可选择按月均发、半年发（6 月和 12 月各半）或指定月份一次性发放，并按实际月份进入累计预扣。
- 默认缴费基数按月薪和当地应计入的房补估算，本年度发放的签字费不自动抬高当年缴费基数；高级设置可为各险种和公积金填写实际申报基数并覆盖估算。
- 以后重新核定缴费基数时，任职相关签字费可能纳入工资总额：北京、上海、广州社保及四城公积金通常计入；深圳社保仅按月发放的签字费可能计入，半年发或一次性发放的签字费不计入其养老保险基数。
- 月度“现金到手”是当月基础工资、房补和签字费扣除个人社保、个人公积金和个税后的可支配金额；月度“含双边公积金所得”= 现金到手 + 个人公积金 + 公司公积金。
- 最终全年所得 = 工资性现金到手 + 全年双边公积金 + 税后年终奖 + 税后股权价值。未启用股权时即为前三部分。
- 股权输入值应是年度内股票期权行权、限制性股票解禁或取得股权奖励时确认的合计应税收入。工具按符合条件的上市公司股权激励处理：不并入综合所得，单独适用综合所得年度税率表。非上市公司递延纳税、转让所得和境外税收抵免不在本简化测算内。
- 年终奖、股权激励均在月度表下方展示税率、速算扣除数、税额和税后价值。
- 公司公积金按与个人相同的实际缴存基数和比例计算。上海基本公积金仍为个人和公司各 5%–7%；补充公积金开关默认启用，按相同基数额外计算个人 5% + 公司 5%，可按实际情况关闭。
- 公积金和未变现股权不属于当月可自由支配现金；最终全年所得是经济价值口径，不等同于银行卡实收现金。
- 北京、广州、深圳住房公积金基本缴存比例范围为 5%–12%，上海为 5%–7%；上海补充住房公积金单位和个人各可按 1%–5% 同比例缴存，本工具按用户情况固定采用各 5%。
- 深圳存量职工使用 2026 公积金年度 2,520 元下限；2026 年 9 月后新参加工作或新调入职工可切换到 2,700 元下限。
- 广东尚未公布新的 2026 社保年度养老基数；广州、深圳沿用最近有效值。广东失业保险单位 0.8%、个人 0.2% 的最近延续文件只明确到 2025 年末，2026 测算暂沿用并在页面提示。
- 单位工伤保险按二类行业 0.4% 估算，实际费率取决于行业类别和浮动档次；单位端估算不影响个人到手金额。

结果仅供测算，实际金额以税务、社保及公积金系统核定为准。
